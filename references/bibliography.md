# 참고문헌

## 기준 교재
**OpenStax, *College Physics 2e*** — https://openstax.org/details/books/college-physics-2e (CC BY 4.0)
- 고른 이유: 무료·공개 라이선스라 그림까지 출처 표기 후 재사용 가능, 비전공자용 대학 교양 물리 수준,
  각 절이 **학습 목표 → 개념 → PhET 탐구 → 요약 → 확인 문제** 구조 → 슬라이드 흐름의 기준으로 채택.
- 강별 대응: 01강 = 18.1·18.2·20.1 / 02~03강 = 20.1·20.2 / 04강 = 21장 / 06강 = 20.5 / 07강 = 19.5·23장

## 설명 순서·비유
**SparkFun, "What is Electricity?"** — https://learn.sparkfun.com/tutorials/what-is-electricity (CC BY-SA 4.0)
- 원자 → 전하 사이의 힘 → 도체 → 정전기 vs 전류 → 전기장 → 전위 → 회로 순서. 01~02강 흐름에 반영.
- 비유: 전자 펌프(건전지), 연쇄 반응(전자가 이웃 전자를 밀어냄), 느린 전자 vs 빠른 전기장.

## 수업 활동
**PhET Interactive Simulations** (University of Colorado Boulder)
- 01강: 풍선과 정전기 — https://phet.colorado.edu/ko/simulations/balloons-and-static-electricity
- 이용 조건: PhET 사이트 기준 확인 필요 (시뮬레이션 화면 캡처 대신 QR 링크로 연결)
